# Eventloop

Eventloop helps students find small local events by vibe: tonight, tomorrow or this weekend.

The pilot city is Madrid, with events in Malasaña, Lavapiés, La Latina, Chueca, Retiro and Chamberí.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## It's a demo

There is no backend. Everything lives in the browser's localStorage and sessionStorage: saved events, bookings, events you create as an organizer, and your account. Sign-in and payment are simulated, so no real accounts are created and no money moves.

## Tech

- Next.js (app router), React 19, TypeScript
- Tailwind CSS 4, shadcn/ui, lucide-react icons
- Inter and Bricolage Grotesque via next/font
