EventLoop patch v2. Copy the app, components and public folders into your existing project and choose Replace. No node_modules or other project files are changed.
Demo images are illustrative assets, not photographs of real listed events. Account dropdown is demo-only; actual authentication is not implemented.
Run npm.cmd run dev.
